**App name:** Excession Labs Security

**Short description (one line):** Check security headers, find penetration testing providers and send a penetration test request.

**Description:**

Excession Labs is a security lab. This app gives your scenarios three tools from its public APIs.

- Check Security Headers: reads the HTTP response headers of a public web page and grades HTTPS, HSTS, CSP, framing, nosniff, referrer policy, permissions policy, COOP and cookie leaks. It reads headers only and is not a penetration test.
- Find Pentest Providers: searches the sourced PentestCompare dataset of penetration testing providers. Filter by name, delivery (human-led, hybrid, automated), covered area and published price. The list is sorted A to Z, not ranked.
- Request a Penetration Test: sends a test request to Excession Labs for a person who asked for it. Excession Labs replies to that person by email. Testing starts only after a written scope and written authorization from the system owner.
- Make an API Call: any other call to penetrationtestservices.com.

The first two modules need no account. Request a Penetration Test needs a free agent key from https://penetrationtestservices.com/auth.md.
